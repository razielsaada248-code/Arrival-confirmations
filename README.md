# Arrival-confirmations
אישורי הגעה לחתונה של אליה ואחינועם

## איך זה עובד
- **`index.html`**: דף אישור ההגעה שהמוזמנים ממלאים. הוא כולל שם פרטי, שם משפחה, טלפון, צד חתן/כלה, תשובה (מגיע / לא מגיע / עוד לא יודע) ומספר מגיעים (1 או 2). מי שבוחר 2 מתבקש למלא גם את שם המלווה.
- **`apps-script/Code.gs`**: קוד שמותקן בתוך Google Sheets ושומר כל תשובה בגיליון.
- בגיליון יש שלוש לשוניות:
  - **תשובות**: כל התשובות, צבועות לפי סטטוס.
  - **סיכום**: כמה נשלחו, כמה ענו, כמה מגיעים (תשובות ואנשים), כמה לא מגיעים, כמה לא יודעים, כמה לא ענו ואחוזים. הכל בסה"כ ולפי צד חתן / צד כלה.
  - **תזכורות**: כל מי שענה "עוד לא יודע", עם כפתור וואטסאפ שפותח הודעת תזכורת מוכנה, ותיבת סימון "נשלח".
  - **שבוע לפני**: כל מי שאישר הגעה, עם כפתור וואטסאפ שפותח הודעה עם פרטי האירוע, קישור ל-Waze וקישור לדף ההזמנה (`invitation.html`), ותיבת סימון "נשלח".
  - **צד חתן** / **צד כלה**: התשובות של כל צד בנפרד. הלשוניות מתעדכנות לבד מתוך "תשובות".
- **שינוי תשובה:** מי שכבר ענה "מגיע" או "לא מגיע" לא יכול לענות שוב, והבדיקה נעשית לפי מספר הטלפון. מי שענה "עוד לא יודע" יכול לענות שוב דרך קישור התזכורת, והתשובה שלו מתעדכנת באותה שורה.
- **קישורים לפי צד:** הקישור `...?side=groom` מסמן אוטומטית צד חתן, והקישור `...?side=bride` מסמן צד כלה. קישור בלי תוספת מציג למוזמן שאלה מאיזה צד הוא.
- **הורדה לאקסל:** בגיליון בוחרים קובץ ← הורדה ← Microsoft Excel (.xlsx).

## התקנה (פעם אחת, כ-10 דקות)

### 1. הגיליון
1. נכנסים ל-[sheets.new](https://sheets.new) עם חשבון הגוגל ויוצרים גיליון חדש. אפשר לקרוא לו "אישורי הגעה – אליה ואחינועם".
2. בתפריט בוחרים **תוספים ← Apps Script**.
3. מוחקים את מה שכתוב שם ומדביקים את כל התוכן של `apps-script/Code.gs`. שומרים.
4. בסרגל העליון בוחרים את הפונקציה `setup` ולוחצים **הפעלה**. גוגל יבקש לאשר הרשאות: לוחצים "Advanced" ואז "Go to ... (unsafe)". האזהרה מופיעה כי זה קוד פרטי שלך ולא אפליקציה מאושרת, וזה תקין.
5. חוזרים לגיליון. נוצרו הלשוניות **תשובות**, **סיכום**, **צד חתן**, **צד כלה**, **תזכורות** ו**שבוע לפני**.

### 2. פרסום הקוד
1. ב-Apps Script לוחצים **פריסה (Deploy) ← פריסה חדשה (New deployment)**.
2. סוג: **Web app**.
   - Execute as: **Me**
   - Who has access: **Anyone**
3. לוחצים Deploy ומעתיקים את הכתובת שמתקבלת. היא מתחילה ב-`https://script.google.com/macros/s/...`.

### 3. חיבור הדף
1. ב-`index.html`, בחלק `CONFIG`, מדביקים את הכתובת בשדה `scriptUrl`.
2. מפרסמים את הדף. האפשרות הפשוטה היא GitHub Pages: בהגדרות המאגר בוחרים Settings ← Pages ← Branch: main. כך מתקבלת כתובת קבועה לשליחה.
3. ב-`Code.gs` מדביקים את כתובת הדף בשדה `FORM_URL`, כדי שהודעות התזכורת יכללו את הקישור. שומרים, ואז **Deploy ← Manage deployments ← עריכה ← New version**.

### 4. שימוש
- שולחים את הקישורים בוואטסאפ: קישור עם `?side=groom` למוזמני צד החתן וקישור עם `?side=bride` למוזמני צד הכלה.
- בלשונית **סיכום** ממלאים ידנית בתאים הצהובים כמה הזמנות נשלחו מכל צד. כל השאר מחושב לבד.
- לתזכורות פותחים את הלשונית **תזכורות**, לוחצים "📲 שלח תזכורת" ומסמנים ✓. אם הרשימה לא עדכנית, בוחרים בתפריט **אישורי הגעה ← רענון רשימות השליחה**.
- שבוע לפני החתונה (12.11) פותחים את הלשונית **שבוע לפני**, לוחצים "📲 שלח הודעה" לכל אחד ומסמנים ✓. בהודעה יש קישור לדף ההזמנה, ותמונת ההזמנה מופיעה בוואטסאפ כתצוגה מקדימה של הקישור.

### הזנה ידנית
אפשר להוסיף אנשים ישירות בלשונית **תשובות**, בשורה ריקה. לעמודות **צד** ו**סטטוס** יש רשימת בחירה, ובעמודה **מספר מגיעים** אפשר להזין רק 1 או 2. הסיכום ולשוניות הצדדים מתעדכנים לבד, וגם רשימות השליחה מתרעננות אחרי כל שינוי בלשונית.

### הבדלים בין הצדדים
- **צד החתן** (`?side=groom`): המוזמנים בוחרים 1 או 2 מגיעים. מי שבוחר 2 ממלא גם עם מי הוא מגיע.
- **צד הכלה** (`?side=bride`): המוזמנים בוחרים מספר מבוגרים (1–10) ומספר ילדים עד גיל 5 (0–10). כשמגיעים יותר מאדם אחד מופיע שדה רשות "שמות המגיעים איתך", והשמות נכנסים לעמודה "שמות המלווים".
- בגיליון, "מספר מגיעים" הוא סה"כ האנשים. העמודות "מבוגרים" ו"ילדים עד גיל 5" נמצאות בסוף הטבלה, ובלשונית הסיכום מופיע הפירוש גם לפי מבוגרים וילדים.
